# b7s-brainstorm

Freestyle daily brainstorm capture — listen without interrupting, organize faithfully, save to `.brainstorms/inbox/{YYYY-MM-DD}.md`, then deepen with `AskUserQuestion`. Spanish (Mexican) personal-use skill.

> Looking for the model-facing contract? See [`SKILL.md`](./SKILL.md).

## Install

```bash
npx behagoras-skills install b7s-brainstorm
```

This wires up the skill at `~/.claude/skills/b7s-brainstorm` and links the `/b7s-brainstorm` slash command.
