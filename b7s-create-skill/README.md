# b7s-create-skill

A mnemonic shortcut to the upstream `skill-creator` skill — the user often remembers `/b7s-create-skill` faster than `/skill-creator` when they want to spin up a new skill quickly. No logic of its own; immediately invokes `skill-creator` with the user's `$ARGUMENTS`.

> Looking for the model-facing contract? See [`SKILL.md`](./SKILL.md).

## Install

```bash
npx behagoras-skills install b7s-create-skill
```
