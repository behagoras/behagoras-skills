# b7s-review

The flip side of [`b7s-brainstorm`](../b7s-brainstorm/README.md). Reviews stored brainstorms, inventories TODOs, and moves files between status folders (`inbox/` → `in-progress/` → `completed/`/`archived/`). Spanish (Mexican) personal-use skill.

> Looking for the model-facing contract? See [`SKILL.md`](./SKILL.md).

npx behagoras-skills install b7s-review
